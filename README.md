# Richard Nzembe Portfolio

Premium dark portfolio built with HTML, CSS and vanilla JavaScript.

## Run
Open `index.html` in a browser or use VS Code Live Server. No build step required. Fonts are loaded from Google Fonts; system fallbacks work offline.

## Before publishing
- Replace the cropped concept artwork in `assets/images/hero-workspace.webp` with your own licensed photo or design if desired.
- The four completed projects use supplied application screenshots and brand assets, with public links to their websites or download pages.
- CV is intentionally marked "coming soon" rather than linking to a missing file. Once your real CV is ready, save it as `assets/cv/Richard-Nzembe-CV.pdf`, replace the CV placeholder in index.html with an anchor pointing to that path and add `download`.
- Add a verified contact email and social links when ready.
- Confirm that all project descriptions and skills reflect your current work.
